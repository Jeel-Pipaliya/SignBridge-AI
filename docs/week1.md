# Week 1 Plan

## Goal

Build the full foundation for SignBridge AI:

Camera -> video frame -> image processing -> MediaPipe-ready frame -> hand/face/pose landmarks -> numerical data -> CSV dataset.

## Day 1

Set up the project, virtual environment, Git, README, and folder structure.

## Day 2

Practice the Python features used in AI work: variables, lists, tuples, dictionaries, loops, functions, classes, file handling, and exceptions.

## Day 3

Explore NumPy and Pandas for landmark arrays, tabular data, filtering, and dataset inspection.

## Day 4

Build OpenCV experiments for webcam capture, resizing, color conversion, blur, thresholding, edges, and ROI handling.

## Day 5

Run MediaPipe hand, face, pose, and holistic detection on live frames.

## Day 6

Extract landmarks into sequences and save them as structured datasets.

## Day 7

Integrate capture, detection, extraction, and persistence into one working pipeline.
